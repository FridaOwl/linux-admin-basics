# UNIX/Linux: Основы администрирования  

Учебный проект по курсу **"Операционные системы UNIX/Linux (Базовый)"**.  
Проект охватывает установку, настройку и базовое администрирование Linux-системы на примере Ubuntu Server.  

## 📌 Содержание  
- Установка и обновление ОС  
- Создание пользователей и настройка прав  
- Настройка сети  
- Работа с системными службами (время, SSHD и др.)  
- Использование текстовых редакторов (VIM, Nano и др.)  
- Мониторинг ресурсов (top, htop)  
- Управление дисками и файловыми системами (fdisk, df, du, ncdu)  
- Просмотр системных журналов  
- Планировщик заданий CRON  

## 📂 Структура репозитория  
```
├── src/                # Основные материалы и отчет в формате .md  
├── misc/               # Вспомогательные материалы (например, изображения)  
│   └── images/  
└── README.md           # Этот файл
```

## 🚀 Как использовать  
1. Клонируйте репозиторий:  
   ```bash
   git clone
   cd linux-admin-basics
   ```
2. Откройте отчет в папке `src/`.  
3. Используйте репозиторий как шпаргалку или учебное пособие по администрированию Linux.  

## 📸 Отчет  
В папке `src/` содержится отчет с выполненными заданиями.  
- Каждое задание оформлено в отдельном разделе.  
- Все скриншоты снабжены подписями.  
- Обрезаны лишние части экрана, чтобы показать только суть.  

## 🛠️ Используемые технологии  
- **Ubuntu 20.04 Server LTS** (без GUI)  
- **VirtualBox** (виртуализация)  
- Стандартные утилиты Linux: `sudo`, `timedatectl`, `fdisk`, `df`, `du`, `cron` и др.  

## 🎯 Цель проекта  
Закрепить базовые навыки системного администрирования Linux:  
- установка и обновление ОС  
- настройка пользователей, сети и служб  
- мониторинг и работа с логами  
- автоматизация задач
